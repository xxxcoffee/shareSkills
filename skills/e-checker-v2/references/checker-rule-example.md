# Checker Rules

在此文件中逐行列出需要检查的规则。每行一条规则。

## 格式说明

规则格式: `[序号] [Excel文件名] [Sheet名] [检查类型] [检查描述]`

## 示例

```
1. 数据表.xlsx 主数据 列存在性 必须包含列: 编号, 名称, 类别, 创建日期
2. 数据表.xlsx 主数据 非空检查 编号, 名称 不能为空
3. 数据表.xlsx 主数据 格式检查 编号必须符合格式: CODE-XXXX (4位数字)
4. 数据表.xlsx 主数据 唯一性检查 编号必须唯一
5. 数据表.xlsx 主数据 一致性检查 创建日期不能晚于失效日期（如有）
6. 数据表.xlsx 明细数据 范围检查 数值字段必须大于0
7. 数据表.xlsx 明细数据 关联检查 编号必须在主数据Sheet中存在
```
